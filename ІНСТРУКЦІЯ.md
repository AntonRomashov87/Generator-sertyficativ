# 📋 Інструкція: розсилка сертифікатів через Gmail

## Що змінилось
Розсилку більше **не робить EmailJS** (він відхиляв великі PDF).
Тепер листи надсилає **Netlify-функція** через ваш Gmail — PDF летить
справжнім вкладенням, без обмежень на розмір.

---

## Файли, які треба покласти на GitHub

Структура репозиторію має бути така:

```
ваш-репозиторій/
├── certificate-generator.html      ← оновлений генератор
├── package.json                    ← список залежностей
├── netlify.toml                    ← конфіг Netlify
└── netlify/
    └── functions/
        └── send-cert.js            ← функція розсилки
```

> Якщо `certificate-generator.html` лежить у підпапці (напр. `/tools/`) —
> це ок, головне щоб `netlify/functions/`, `package.json` і `netlify.toml`
> були в **корені** репозиторію.

---

## Крок 1. Залити файли на GitHub

```bash
git add certificate-generator.html package.json netlify.toml netlify/
git commit -m "Розсилка сертифікатів через Gmail (Netlify function)"
git push
```

## Крок 2. Додати пароль Gmail у Netlify (НЕ в код!)

1. Відкрийте свій сайт на **app.netlify.com**
2. **Site configuration** → **Environment variables** → **Add a variable**
3. Додайте **дві** змінні:

   | Key              | Value                                    |
   |------------------|------------------------------------------|
   | `GMAIL_USER`     | `romashov1987@gmail.com`                 |
   | `GMAIL_APP_PASS` | ваш 16-значний пароль додатку (без пробілів) |

4. Збережіть.

## Крок 3. Передеплой

Netlify передеплоїть автоматично після `git push`. Якщо додали змінні
**після** пушу — натисніть **Deploys → Trigger deploy → Deploy site**,
щоб функція побачила нові змінні.

---

## Крок 4. Тест

1. Відкрийте свій сайт-генератор
2. Завантажте обидва Excel, оберіть учасників
3. Вкладка **Розсилка Email** → спочатку перевірте на **1-2 своїх адресах**
   (можна тимчасово залишити у файлі контактів лише себе)
4. Натисніть **Надіслати**

Якщо прийшов лист із PDF — усе працює, шліть решті. ✅

---

## Якщо помилка

- **500, "не налаштовані змінні"** → перевірте крок 2 і зробіть Trigger deploy
- **535 / auth failed** → пароль додатку введено з пробілами або неправильно.
  Створіть новий на `myaccount.google.com/apppasswords` і оновіть у Netlify
- **інша помилка** → відкрийте на Netlify **Functions → send-cert → логи**,
  там буде точна причина. Скиньте мені текст — розберемось.

---

## Безпека
- Пароль додатку **не** зберігається в коді — лише в захищених змінних Netlify.
- Пароль додатку дає доступ **лише до відправки пошти**, не до всього акаунта.
- У будь-який момент можна відкликати його на `myaccount.google.com/apppasswords`.
